# ADR 0001: Границы monorepo и процессов

- **Статус:** принято
- **Дата:** 31.08.2026

## Контекст

HarmoFin включает web-интерфейс, HTTP API и фоновые задачи. Продуктовая модель должна оставаться единой, но процессы должны запускаться и масштабироваться независимо.

## Решение

Используем TypeScript monorepo и модульный монолит. `apps/web`, `apps/api` и `apps/worker` — отдельные приложения. Web не импортирует runtime-код API, API не импортирует web-компоненты, worker переиспользует application services после их появления и не копирует бизнес-правила.

## Последствия

Разработка и локальный запуск используют один repository и общий lock-файл. Границы зависимостей остаются видимыми до возможного выделения отдельных сервисов. Раннее внедрение микросервисов и Kubernetes не требуется.

## Условия пересмотра

Решение пересматривается при измеримой потребности в независимом масштабировании, изоляции команд, SLA или отказоустойчивости.

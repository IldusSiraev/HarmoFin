# ADR 0002: pnpm workspaces без task runner

- **Статус:** принято
- **Дата:** 31.08.2026

## Контекст

Этап 0 требует небольшого monorepo с едиными командами качества. Дополнительный task runner увеличил бы конфигурацию до появления сложного графа задач.

## Решение

Используем pnpm workspaces, один lock-файл и штатные recursive/parallel scripts. Turborepo и Nx не добавляем.

## Последствия

Команды прозрачны и одинаковы локально и в CI. Кеширование и расширенный task graph пока отсутствуют, но могут быть добавлены отдельным решением при подтвержденной потребности.

## Условия пересмотра

Решение пересматривается при существенном росте workspace, длительности CI или появлении повторяемых задач, которые pnpm scripts не могут эффективно оркестрировать.

# ADR 0003: PostgreSQL как источник истины

- **Статус:** принято
- **Дата:** 31.08.2026

## Контекст

Финансовые данные требуют транзакционности, ограничений целостности и восстановления. Локальная разработка должна иметь минимум внешних зависимостей.

## Решение

PostgreSQL является источником истины для данных HarmoFin. На Этапе 0 Docker Compose поднимает только PostgreSQL 18 с healthcheck и named volume. Production managed PostgreSQL, резервирование и PITR относятся к последующим этапам.

## Последствия

Readiness API проверяет реальную доступность PostgreSQL. Локальные данные сохраняются между перезапусками Compose. Development credentials из `.env.example` не предназначены для staging или production.

## Условия пересмотра

Решение пересматривается только отдельным архитектурным решением о совместимом хранилище или изменении deployment strategy; кеш не может стать источником истины.

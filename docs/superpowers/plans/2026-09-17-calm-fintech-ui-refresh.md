# Calm Fintech UI Refresh — Tracking Checklist

**Ветка:** `design/calm-fintech`
**Направление:** «Calm Fintech / Editorial Finance» — согласовано с пользователем 17.09.2026 после двух отклонённых попыток («generic AI SaaS», «Ledger»).
**Источники:** [Предложения UI.md](../../chat_gpt/Предложения%20UI.md) (текстовый бриф с ASCII-макетами и hex-палитрой), приложенные скриншоты (сторонний пример «Budglee», собственный мокап HarmoFin от ChatGPT), Figma Make прототип пользователя (полное HarmoFin UI на 8 страниц, structurally почти идентичен нашей IA — сверялись по нему, но сайдбар оставили свой по явному запросу пользователя).
**Не входит в объём:** новые бизнес-правила, изменения API/домена — только `apps/web` presentation layer.

Отмечать `[x]` по мере выполнения каждого пункта, чтобы не потерять список между сессиями.

## Готово

- [x] Палитра токенов (`tokens.css`): Navy/Teal/Green/Blue/Mint вместо generic slate/blue, мягкие тени, более скруглённые поверхности.
- [x] Иконки в сайдбаре (`AppSidebar.vue`) + приглушённый неактивный пункт / teal-пилл активного.
- [x] Hero-карточка «Можно потратить» (`AvailableBudgetCard.vue`): кикер → крupная сумма → «до {дата} · осталось N дней» → прогресс → статус → строка из трёх колонок (Потрачено / Было доступно / В среднем в день).
- [x] Операции как activity feed — проверено вживую: страница уже группирует по дню (`groupByDay`) и рендерит карточные строки (`OperationRow`/`OperationGroup`), а не таблицу; фильтры уже в виде chip-кнопок (Период/Счёт/Категория/Конверт/Тип). Изменений не потребовалось — новая палитра прилетела через токены автоматически.
- [x] «Финансовый месяц» как визуальный таймлайн (`FinancialMonthTimeline.vue`, новый компонент на дашборде): полоса с заливкой до сегодня, точка «вы здесь», засечка границы периода, подписи дат начала/конца цикла. Сверено с макетом на Figma (см. ниже) — там тоже просто текстовая строка, но визуальная полоса читается понятнее и не противоречит направлению.
- [x] Флоу «+ Операция» — пошаговый для создания (`OperationForm.vue`): Шаг 1 «Когда и сколько» (тип/дата/сумма) → Шаг 2 «Счёт» → Шаг 3 «Категория» → Шаг 4 «Детали» (конверт/получатель или источник/план) с кнопками Назад/Далее, «Далее» заблокирована пока текущий шаг не заполнен. Режим редактирования сознательно остался одним экраном со всеми полями сразу — при правке уже существующей операции пошаговость только мешает. Проверено вживую сквозным сценарием (создание нового расхода по всем 4 шагам).

- [x] Категории — двухколоночная раскладка (Доходы слева / Расходы справа), плоский список вместо карточной сетки: корневые категории обычной строкой, дочерние — с отступом и маленькой иконкой-аватаром (переиспользован `categoryIcon` из журнала операций). Действия «Изменить»/«В архив» стали компактными icon-only кнопками вместо больших цветных пилюль — по референсу стороннего проекта (FamFi), который прислал пользователь в процессе работы. Добавлен тест на вложенность (родитель/ребёнок в одном списке, ребёнок с классом `category-row--child`).

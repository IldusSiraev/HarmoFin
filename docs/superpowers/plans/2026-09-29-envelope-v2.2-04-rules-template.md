# HarmoFin: план реализации Envelope Plan v2.2 — 04. Правила, предложения и шаблон

> **Для исполнителя:** одна задача за сессию, TDD, отчёт и стоп; без субагентов/worktree. Читайте [индекс](2026-09-29-envelope-v2.2-00-roadmap.md), [спецификацию §5–7, §11–12](../specs/2026-09-29%20HarmoFin_Envelope_Plan_Model_v2.2.md) и только свой Task.

**Цель:** Предлагать назначения из реальных денег в порядке предпочтений пользователя без автопроведения; настроить новый базовый шаблон без v1 «Свободных».

**Архитектура:** Сохранённое правило/цель не является движением денег. Preview читает актуальные balances/occurrences, предлагает строки, confirm под блокировкой пересчитывает и атомарно записывает assignment; шаблон создаёт только справочники/правила. Все суммы minor bigint.

**Стек:** Node.js 24.20.0, pnpm 11.24.0, NestJS/Fastify, Prisma/PostgreSQL 18, Vitest, OpenAPI.

**Спецификация:** [v2.2](../specs/2026-09-29%20HarmoFin_Envelope_Plan_Model_v2.2.md).

## Общие ограничения

- Примерные суммы и даты владельца не зашивать. Доход создаётся независимо от preview; категория → конверт только предложение. Реальные назначения — только подтверждение владельцем/разрешённой ролью, CSRF+idempotency+audit.
- `period_funded` включает явный перенос, но **не** уменьшается от расхода. Сохранённый периодный target не переписывается изменением правила; доработки текущего периода — явные действия.
- Integration только disposable DB; browser Playwright только CI. Каждый task — локальные unit/integration/typecheck и отдельный коммит.

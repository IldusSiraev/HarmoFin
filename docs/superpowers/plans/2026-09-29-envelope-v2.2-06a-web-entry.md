# HarmoFin: план реализации Envelope Plan v2.2 — 06a. Быстрый ввод и настройка web

> **Для исполнителя:** одна задача за сессию, TDD, отчёт и стоп; без субагентов/worktree. Читайте [индекс](2026-09-29-envelope-v2.2-00-roadmap.md), [спецификацию §11 и Calm Fintech](../specs/2026-09-17-calm-fintech-visual-guidelines.md) и только свой Task. Локально Playwright не запускать.

**Цель:** Подтвердить предложение назначения и оплатить план за несколько действий, без типовой длинной формы и без двойного проведения денег.

**Архитектура:** `useEnvelopePlanV2` — тонкий типизированный API-клиент, все суммы приходят строками с сервера. Общий компонент review-панели используется после дохода/начального баланса и при ручном пополнении; существующий быстрый диалог операции остаётся одноэкранным. Бюджеты v1 сохраняют прежний UI до cutover.

**Стек:** Node.js 24.20.0, pnpm 11.24.0, Nuxt 4/Vue 3, @lucide/vue, CSS tokens HarmoFin, Vitest/@vue/test-utils.

**Спецификация:** [v2.2](../specs/2026-09-29%20HarmoFin_Envelope_Plan_Model_v2.2.md).

## Общие ограничения

- Русский UI, Inter, те же tokens/light/dark; не добавлять библиотеку UI/иконок. Минимум действий, сумма крупная, поля-состояния доступные с клавиатуры, ошибки рядом с вводом.
- Ни одной денежной формулы в web: только показ DTO и редактирование строк; `BigInt`/decimal strings только для валидации ввода, итог подтверждает сервер. Idempotency-Key один на попытку, при retry сохраняется.
- Локально web unit/typecheck; браузерные E2E — только CI. Задачи не меняют v1 UI без ветки по `planModelVersion`.

## Карта файлов

- `apps/web/app/composables/useEnvelopePlanV2.ts`, `.test.ts` — v2 запросы, бюджетная версия.
- `apps/web/app/components/funding/FundingReviewSheet.vue`, `.test.ts` — короткий предпросмотр и правка, без расчётов денег как JS number.
- `apps/web/app/components/funding/TemplatePreviewSheet.vue`, `.test.ts` — ввод основных целевых сумм/опций.
- `apps/web/app/components/obligations/ObligationPaySheet.vue`, `.test.ts` — ввод фактической оплаты из плана.
- `apps/web/app/components/app/AppOperationEntryDialog.vue`, `apps/web/app/pages/app/{operations,transfers,plans}.vue`, `apps/web/app/pages/app/settings/index.vue`, `apps/web/app/components/dashboard/OnboardingChecklist.vue` — интеграция с существующей навигацией.

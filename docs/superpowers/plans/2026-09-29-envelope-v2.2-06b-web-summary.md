# HarmoFin: план реализации Envelope Plan v2.2 — 06b. Сводка и просмотр web

> **Для исполнителя:** одна задача за сессию через субагентов, TDD, review, отчёт и стоп; без worktree. Читайте [индекс и порядок работы](2026-09-29-envelope-v2.2-00-roadmap.md), [спецификацию §8–11](../specs/2026-09-29%20HarmoFin_Envelope_Plan_Model_v2.2.md), [Calm Fintech](../specs/2026-09-17-calm-fintech-visual-guidelines.md) и только свой Task. E2E — CI, НЕ локально.

**Цель:** Показать одно честное главное число, остатки назначений и историю без старой модели физических конвертов.

**Архитектура:** Web budget2 получает агрегаты и статусы от P01–P05, не считает ограничения самостоятельно. Старые страницы budget1 работают до cutover. Списки/карточки используют нынешние токены и иконки, действия переназначения открывают компактную панель W02.

**Стек:** Node.js 24.20.0, pnpm 11.24.0, Nuxt 4/Vue 3, CSS tokens HarmoFin, @lucide/vue, Vitest.

**Спецификация:** [v2.2](../specs/2026-09-29%20HarmoFin_Envelope_Plan_Model_v2.2.md).

## Общие ограничения

- Русские тексты, достаточный контраст, видимый фокус, icon-only действия с aria-label. Реальный cash, текущий остаток, safe и свободно для назначения — **разные** показатели.
- Деньги/лимиты с API; не использовать `Number(BigInt(...))` для исходных расчётов. Предусмотреть light/dark и мобильный viewport; Playwright только CI.

## Карта файлов

- `apps/web/app/components/dashboard/AvailableBudgetCard.vue`, `DashboardWarnings.vue`, `PeriodLeftoverPrompt.vue`, `OnboardingChecklist.vue`; `apps/web/app/pages/app/index.vue` — ответ/действия.
- `apps/web/app/components/envelopes/EnvelopeRow.vue`, `EnvelopeDrawer.vue`, `apps/web/app/pages/app/envelopes.vue` — назначения и цели.
- `apps/web/app/pages/app/{analytics,notifications,help}.vue`, `apps/web/app/components/funding/RuleSettingsSheet.vue` — отчёты/настройки/объяснения.

### Задача S02: История периода и явный перенос остатка

**Файлы:** Create `apps/web/app/components/dashboard/PeriodDecisionCard.vue`, `PeriodDecisionCard.test.ts`; Modify `apps/web/app/pages/app/index.vue`; Test page tests.

**Интерфейсы:** При открытии нового периода показывает draft цели `FIXED_PER_PERIOD` с отдельным «Подтвердить план» (R01c) либо одновременным подтверждением с назначением в W02; до этого цель — предложение, не действующий лимит. При положительном остатке прошлого периода предлагает «В следующий», «В накопления», «В обязательные», «Вернуть в свободные», «Оставить пока»; вызывает W01 move либо assignFree только после явного подтверждения. При отрицательном — задача покрытия, не источник переноса.

```ts
expect(api.move).not.toHaveBeenCalled(); // before explicit confirmation
expect(wrapper.text()).toContain('Оставить пока');
```

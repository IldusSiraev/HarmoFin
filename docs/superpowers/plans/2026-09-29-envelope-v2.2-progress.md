## Как вести журнал

После **одной** задачи и локальных проверок добавить запись ниже, назвать следующий ID и остановиться. Если задача не завершена, указать точный блокер и не отмечать чекбоксы в файле этапа. Не отмечать Playwright пройденным без результата CI. Для незакоммиченного исправления E2E/CI указать «коммит ожидает подтверждения владельца». Никаких паролей, URL с секретами, настоящих сумм/пользовательских payload.

Шаблон строки: `YYYY-MM-DD | ID | SHA или «без коммита» | проверено: <конкретные команды/CI> | следующий: ID | блокер: нет/причина`.

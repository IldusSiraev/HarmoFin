## Как вести журнал

После **одной** задачи, работы субагента-исполнителя, независимого read-only review и локальных проверок добавить запись ниже, назвать следующий ID и остановиться. Все субагенты работают в текущем checkout без worktree, одновременно только один редактирует файлы; порядок — в [индексе](2026-09-29-envelope-v2.2-00-roadmap.md). Если задача не завершена, указать точный блокер и не отмечать чекбоксы в файле этапа. Не отмечать Playwright пройденным без результата CI. Для незакоммиченного исправления E2E/CI указать «коммит ожидает подтверждения владельца». Никаких паролей, URL с секретами, настоящих сумм/пользовательских payload.

Шаблон строки: `YYYY-MM-DD | ID | SHA или «без коммита» | проверено: <конкретные команды/CI> | следующий: ID | блокер: нет/причина`.

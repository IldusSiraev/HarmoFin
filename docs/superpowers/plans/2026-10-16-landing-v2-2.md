# Лендинг под модель v2.2 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Переписать главную страницу `apps/web/app/pages/index.vue` под модель Envelope Plan v2.2: 8 секций, тексты по глоссарию, витрины из настоящих компонентов приложения вместо ручных макетов, без несуществующих графиков.

**Architecture:** Новые секции лендинга рендерят presentational-компоненты приложения (`AvailableBudgetCard`, `BalanceList`, `EnvelopePlanRow`, `UpcomingObligations`, `PeriodDecisionCard`, `GoalProgressReport`, `PlanVsActualReport`) с типизированными демо-DTO из `data/landing-demo.ts`. Каждая витрина обёрнута в `LandingShowcase` (`<figure>` + `<div inert>` + `<figcaption>`), поэтому клики, фокус и вызовы API внутри витрин отключены. Тексты лендинга — в `data/landing.ts` и шаблонах секций. Старые секции и каталог `mockups/` удаляются.

**Tech Stack:** Nuxt 4, Vue 3.5, TypeScript strict, `@lucide/vue`, Vitest, Playwright (только CI).

**Spec:** [docs/superpowers/specs/2026-10-16-landing-v2-2-design.md](../specs/2026-10-16-landing-v2-2-design.md)

## Global Constraints

- Тексты интерфейса — на русском, строго по глоссарию [2026-10-16-ui-glossary-design.md](../specs/2026-10-16-ui-glossary-design.md), раздел 3. Запрещены на лендинге: `назнач` (любой регистр), `Свободные`, `Обязательства`, `Периодн`, `Пользовательская`, `защищен`, `горизонт`.
- Обещать только то, что есть в приложении. Никаких графиков, пока нет задачи B.
- Деньги в демо-данных — строки integer minor units; на лендинге нет арифметики с деньгами.
- На лендинг не импортируются `echarts`, `ReportChart.vue`, `pages/app/analytics.vue`. Тест `pages/index.build-chunks.test.ts` не меняется.
- Компоненты приложения (`components/dashboard/**`, `components/envelopes/**`, `components/analytics/**`) не меняются ради лендинга.
- Визуальные правила — [Calm Fintech guidelines](../specs/2026-09-17-calm-fintech-visual-guidelines.md): токены `--hf-*`, карточки, светлая и тёмная темы, иконки `@lucide/vue`.
- Якоря: `#features`, `#how-it-works`, `#security`, `#faq`. CTA «Начать бесплатно» → `/register`; «Войти» в шапке → `/login`; вопрос FAQ «Что такое HarmoFin?» сохраняется.
- Тесты лендинга минимальны (решение владельца): один тест запрещённых терминов, обновлённый E2E. Новые unit-тесты на секции не пишутся.
- Работа в текущем checkout, без worktree. Локальный Playwright не запускать. Не коммитить, не пушить без явного разрешения владельца.
- Исполнитель — один writer (`frontend-engineer`); ревью — `ui-ux-reviewer`, `qa-reviewer`, `final-code-reviewer`.

На счетах: Карта 142 000 + Накопительный счёт 82 000 + Наличные 8 300 = 232 300
Текущие траты (вторая половина, текущий период): отложено 65 000, потрачено 33 500, остаток 31 500
Текущие траты (первая половина, прошлый период): остаток 4 300 — ждёт решения
Обязательные платежи: остаток 52 000; к оплате до 9 октября 48 000 (36 000 + 900 + 11 100)
Ремонт 70 000, Отпуск 42 000, Резерв 15 000
Отложено на обязательные = max(52 000, 48 000) = 52 000
Накопления и прочее = 70 000 + 42 000 + 15 000 + 4 300 = 131 300
После отложенного = 232 300 − 52 000 − 131 300 = 49 000
Можно потратить = min(31 500, 49 000) = 31 500
Не распределено = 232 300 − (31 500 + 4 300 + 52 000 + 70 000 + 42 000 + 15 000) = 17 500
В среднем в день = 31 500 / 7 = 4 500
```

import { readdirSync, readFileSync } from 'node:fs';
import path from 'node:path';

import { describe, expect, it } from 'vitest';

// The landing speaks the UI glossary (docs/superpowers/specs/2026-10-16-ui-glossary-design.md):
// none of the internal model terms may reach a visitor.
const FORBIDDEN = [/назнач/i, /Свободные/, /Обязательства/, /Периодн/, /Пользовательская/, /защищен/i, /горизонт/i];

const appRoot = path.resolve(__dirname, '..');

function landingSources(): string[] {
  const dir = path.join(appRoot, 'components/landing');
  const vueFiles = readdirSync(dir, { recursive: true, encoding: 'utf8' })
    .filter((file) => file.endsWith('.vue'))
    .map((file) => path.join(dir, file));
  return [
    ...vueFiles,
    path.join(appRoot, 'data/landing.ts'),
    path.join(appRoot, 'data/landing-seo.ts'),
    path.join(appRoot, 'pages/index.vue'),
  ];
}

describe('landing copy', () => {
  it.each(landingSources())('uses only glossary terms in %s', (file) => {
    const text = readFileSync(file, 'utf8');
    for (const pattern of FORBIDDEN) {
      expect(text, `${path.relative(appRoot, file)} matches ${pattern}`).not.toMatch(pattern);
    }
  });
});
```

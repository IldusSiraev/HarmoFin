# Понятные термины в интерфейсе — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить внутренние термины модели («назначить», «назначено», «план периода», «обязательства», «периодная» и т. п.) единым пользовательским словарём во всех текстах, которые видит пользователь.

**Architecture:** Меняются только строки: шаблоны и словари сообщений `apps/web`, `detail`/`message`/заголовки CSV и совпадающие с ними `example` DTO в `apps/api`, тексты в unit/integration/E2E-тестах, глоссарий функциональной спецификации. Логика, коды ошибок, API-контракт, `data-testid`, имена в коде не меняются.

**Tech Stack:** Nuxt 4/Vue 3.5, `@vue/test-utils`, NestJS/Fastify, Vitest (unit + integration через `server.inject`), Playwright (только CI).

**Spec:** [docs/superpowers/specs/2026-10-16-ui-glossary-design.md](../specs/2026-10-16-ui-glossary-design.md)

## Global Constraints

- Словарь — раздел 3 спецификации. Новых терминов не придумывать; если фраза теряет точность, написать об этом в отчёте задачи.
- Автозамена по корню «назнач» запрещена. Каждая строка правится вручную по таблицам ниже.
- «Назначение» в смысле «цель, предназначение денег» не меняется: `AuthForm.vue:33`, `ConceptSection.vue:14`, `FinalCtaSection.vue:16`, `ProblemSection.vue:31`, `data/landing.ts:241`, `data/landing.ts:247`, «по назначению» в `EnvelopesPlanView.vue:391`, «предназначен…» везде, колонка `'Назначение'` (`purposeName`) в `transactionHeaders` CSV.
- Не меняются: имена в коде, API, БД, коды ошибок, `data-testid`, маршруты, `summary`/`description` OpenAPI, комментарии в коде, названия тестов (`it(...)`, `describe(...)`), «цикл», «период», «цель периода», «Правило пополнения», «Перерасход», «Перенос», «Защищённый доступ» на лендинге.
- Тесты сначала: в каждой задаче ассерты меняются на новые тексты до правки компонентов, прогон показывает падение, затем правка текстов.
- После правки шаблонов — `pnpm format` для затронутых файлов: длина строк меняется, prettier может переносить текст.
- Локально Playwright не запускать; E2E правится и проверяется в CI.
- Не коммитить, не пушить без явного разрешения владельца. Задачи заканчиваются проверкой, без коммита.
- Не трогать `identity/logo_description.png`. Не создавать worktree.

export function planScopeNote(envelopeType: string): string {
  if (envelopeType === 'SAVINGS_GOAL' || envelopeType === 'RESERVE') {
    return 'Остаток не сбрасывается при смене периода';
  }
  if (envelopeType === 'MANDATORY_EXPENSES') {
    return 'Аренда, кредиты, коммунальные и другие регулярные платежи';
  }
  if (envelopeType === 'CURRENT_EXPENSES') {
    return 'Остаток прошлого периода переносится только по вашему решению';
  }
  return 'Деньги на любую цель без привязки к периоду';
}

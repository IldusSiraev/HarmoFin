Зависимости и overrides не менялись. По независимой проверке Security reviewer: в production-графах API (73 узла) и worker (26 узлов) нет picomatch; в исходниках apps/packages нет импорта, в готовом web runtime нет модуля/parser. Эксплуатация требует контролируемого атакующим glob pattern; одних входных строк для сопоставления недостаточно. В tooling используются шаблоны репозитория.

Это принятие проверенной неприменимости к runtime, а не исправление самой upstream-уязвимости. Итоговый Security verdict по точному исключению: APPROVE. Совместный QA/final review: APPROVE.

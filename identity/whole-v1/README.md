# HarmoFin — «Общее целое», версия 01

Выбранное владельцем направление: три неравные части, мягкий почти квадратный силуэт, разветвлённый просвет. Векторная версия одобрена владельцем и подключена к интерфейсу приложения через общий компонент BrandLogo.

## Файлы

- `mark.svg` — основной знак с прозрачным фоном.
- `mark-mono.svg`, `mark-inverse.svg` — одноцветные версии, одна геометрия.
- `logo.svg`, `logo-inverse.svg` — горизонтальное сочетание знака и названия, надпись в кривых, внешние шрифты не нужны.
- `app-icon.svg`, `app-icon-512.png` — иконка на тёмной подложке.
- `mark-16.png` … `mark-48.png` и одноцветные аналоги — настоящие растровые размеры для проверки.
- `preview.png`, `preview.svg` — лист примерки. Шапка и боковое меню являются статическими макетами, а не снимками работающего приложения.

## Решения

Плоские заливки: Navy `#0D1B2A`, Teal `#1BA39C`, Mint `#73C6B6`. Без градиентов, теней и обводок. Базовый холст 256 × 256; видимая область 224 × 224, отступ по 16 единиц. Все варианты используют те же три контура. На тёмном фоне используется белая версия; иконка приложения имеет собственную тёмную подложку.

Надпись выполнена Segoe UI Bold, переведена в кривые. Это осознанная первая примерка системного fallback-шрифта приложения; это **не Inter**. Основной интерфейс остаётся на Inter. Перед окончательным утверждением можно заменить надпись на Inter с проверкой оптического баланса.

«Общее целое» — название концепции, не слоган. Три части не закрепляются за конкретными типами конвертов: это образ целого бюджета, а не финансовая диаграмма.

Предварительное охранное поле: не меньше 1/4 ширины видимого знака. Размер 16 px — техническая проба, не утверждённый минимальный размер. В интерфейсе предпочтительно 24 px и больше; проверка живой страницы и favicon в браузере остаётся отдельным шагом интеграции.

## Воспроизведение

`build.cjs` собирает SVG и PNG через локальный bundled Sharp. `wordmark-source.json` хранит контур надписи, полученный из установленного Segoe UI Bold через Windows GraphicsPath. Путь к Sharp в скрипте относится к текущей машине; для переносимого запуска его потребуется заменить. Продуктовые зависимости не добавлялись.

## Объём и проверка

Подготовить знак → собрать версии → растрировать 16/24/32/48 px → проверить геометрию и визуальную примерку → показать владельцу. Изменения ограничены этой папкой. Исходный `identity/logo_description.png` не изменяется. Иллюстрации и подключение к приложению в этот шаг не входят.

## Подключение к приложению

`apps/web/app/components/brand/BrandLogo.vue` использует одобренные контуры знака и надписи Segoe UI Bold. В тёмной теме и на фиксированном тёмном блоке входа применяется белая версия. `apps/web/public/brand/mark.svg` — мастер для воспроизводимого генератора favicon и PWA-иконок `apps/web/scripts/generate-pwa-icons.mjs`. Маскируемая иконка имеет непрозрачную подложку, знак проверяется внутри безопасного круга платформы.

`wordmark-comparison.html` сравнивает одобренную надпись с Inter из существующего локального файла шрифта. Это отдельная примерка, Inter в логотипе приложения не включён. Живая браузерная проверка интеграции описывается в отдельном отчёте задачи.
